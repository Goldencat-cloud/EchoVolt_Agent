# 归因：为什么这么说

## 何时用

报告里出现因果或驱动解释时（"因为产能爬坡""由购前预期驱动"）。纯描述型报告不用读。

## 四要素（缺一不可）

1. **机制**：一句话说明解释逻辑（为什么）
2. **支持证据**：绑定已验证数字（带口径）与代表引文（带 claim_id）
3. **替代解释检查**：至少列 1 个竞争性解释并说明为何弱（如话题结构自选择、收录偏差）
4. **置信度**：高/中/低——依据样本规模与证据类型（亲历 > 后验担忧；全量计数 > 小组抽样）

## 常见错误

- ✅ "交付等待抱怨由产能爬坡与竞品促销叠加驱动（近期 8 条中 5 条来自未拥有者，精选子集，n=8）——替代解释：该议题天然吸引购前人群（无法排除）；置信度：低"
- ❌ "服务负面部分由购前预期驱动"（无样本量、无替代解释、无置信度）
- ❌ 把相关当因果：两个议题同期上升，不等于前者导致后者
- ❌ 每条结论都配归因：没有机制证据的，就只写事实

## 自查一句

每条归因都能被反问："你怎么排除另一种解释？"——答不上来就降置信度或改写为事实描述。
