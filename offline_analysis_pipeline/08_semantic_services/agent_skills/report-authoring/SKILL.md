# 报告撰写与提交

## 角色与读者

服务对象：准备提交报告的 Agent。输出标准：通过 report_gate 的五段结构中文报告——每个数字可核验、每条引用可回溯、面向业务负责人说业务语言。先结论后依据，长度上限以服务端门禁为准（超限时返回具体修订要求）。

## 撰写流程

1. **搭五段骨架**（顺序固定）：
   1. **结论摘要**：先回答用户问题，3–5 条，每条一句结论 + 带口径的核心数字；只写有证据支撑的。小样本（n < 30）句尾标「（置信度：低，n=12）」。
   2. **分项事实**：每个 workstream 一小节，数字必须来自工具或代码结果并带口径。
   3. **证据与归组**：观点归组与代表引文，遵守下文「证据与引文」。
   4. **限制与不确定性**：数据集合边界、数据状态、未覆盖维度，如实写。
   5. **待验证问题**：本数据无法回答、值得下一步追问的问题。
2. **逐个数字过口径**：见「数字表述」——分母属于哪级、集合是精选还是全量、是否混用两种占比。
3. **核对引文与归组**：见「证据与引文」。
4. **归因段（趋势型报告才写）**：读 `reference/build-argument.md` 的归因四要素。
5. **换用户语言**：见「术语对照」，不得出现工具名、工作流名、代码概念。
6. **提交**：调用 `submit_report`（title/markdown/key_findings）；正文必须写出任务简报给出的当前数据版本（如页脚「数据版本：<版本号>」，原样照抄，不自行推断）；被拒则按返回的修订要求修改重提，重提上限见工具说明；超限仍失败则如实报告失败。

## 数字表述

**两级分母，不混用、不互相推导**：

| 分母 | 定义 | 判断依据 |
|---|---|---|
| 观点级 | 负面观点 ÷ 观点总数 | 指标名含 Share，粒度=观点 |
| 帖子级 | 负面帖子 ÷ 帖子总数 | 指标粒度=帖子 |

指标的正式口径文案以工具返回的 `caliber` 字段为准，直接引用，不自己重组。

- ✅ "负面观点占比 55.1%（54/98 条观点）；相关帖子中 52/90 帖含负面反馈"
- ❌ "90 个帖子里 54 个是负面的"（观点级分子套帖子级分母）

**集合口径**：以本次简报与工具返回为准——精选子集不表述为全量，全量产品关联主张不称为精选。证据匹配通过不等于语义正确，也不代表所有用户。带时间过滤时注明区间。

**样本或证据不足时**：写「样本不足（n=N），仅作线索」，不给占比、不说"多数/普遍/集中"。宁缺数字，不做外推。

**品牌范围声明（必写，gate 校验）**：正文须含「分析主体」或「品牌范围」，名称与范围取自任务简报（技能不写死品牌）。简报覆盖声明中的其他品牌仅为帖子共现对比信息，不表述为分析对象。缺失即拒。

**数据状态**：以简报覆盖声明为准；标注为临时/占位样本时，结论必须带此边界。

**图表**：`bar`/`line`/`pie` 出图；`table` 由正文表格承载，不额外出图。标题用计划的 `visualization.title`，锚在对应章节并紧跟数字依据，图表数值与正文同源（gate 并入溯源）。图例与坐标轴用业务词，不出现内部词。

## 证据与引文

- **逐字**：引文与 evidence 返回的 `quote` 逐字一致，不改写、不缩写、不拼接；每条带 `claim_id`。发布版自动附证据索引（claim_id → 链接/日期），不自行编造链接或日期。
- **标注归组方式**：每组开头写「归组方式：统计计数」或「归组方式：内容归纳（作者判断，非统计结果）」。
- **计数不外推**：组内计数（如"4/8 条"）只对该组成立；未归组计数的引文不用"多数/普遍/集中"。
- **个例不作统计**：归组判断只能来自统计方法或代码结果，引文只作说明。
- 新管道仅引用匹配通过的证据，并标明图片描述并非原帖正文。

- ✅ "典型抱怨如『充电排队两小时』（claim_id: ab12…，精选子集，该组共 17 条）"
- ❌ "很多用户反映充电排队两小时"（无数值、无出处）

## 术语对照（面向用户）

| 内部字段 | 用户表述 |
|---|---|
| claims | 观点条数 |
| journey | 用户所处阶段 |
| ownership | 车主/关注者 |
| negativeShare | 负面观点占比（按观点条数） |
| workstream | 分析子问题 |
| 精选口径 | 精选观点样本 |

作用域=全部用户可见文本。指标与维度的正式名称以语义目录的 `label` 为准，本表仅为常用对照。

## 完成标准（提交前逐项勾选）

- [ ] 五段齐全且顺序正确
- [ ] 每个数字标了所属分母与集合；没有跨分母换算
- [ ] 每条引文有 `claim_id` 且与 `quote` 逐字一致；每组标了归组方式
- [ ] 正文写出了当前数据版本（简报中的版本号，原样照抄）
- [ ] 正文含分析主体/品牌范围声明
- [ ] 用户可见文本无内部字段名、工具名、工作流名
- [ ] 小样本结论已标注置信度；样本不足处未给占比
