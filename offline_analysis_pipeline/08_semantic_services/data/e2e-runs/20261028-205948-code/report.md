# SU7 整体负面观点占比：按观点条数加权（20.41%）与各议题简单平均（22.84%）的对照

**品牌范围**：分析主体为小米/SU7；快照中的其他品牌（特斯拉、极氪、保时捷、比亚迪、阿维塔、尚界）仅为帖子共现对比信息，不作为本次分析对象。

**数据版本**：上一版本数据（V2.3 抽取 + AUTO-018 V2 delivery-r3），占位性质。快照校验 ba7dc3feac35，构建于 2026-10-25；本报告结论须带此临时样本边界，不作为正式研究结论发布。

**口径分区**：本报告的占比与计数一律取自「全量声明级」指标——负面观点占比 = 负面观点条数 ÷ 该议题观点条数，分母为该议题在冻结快照内的全部观点声明；时间覆盖 2023-12-24 至 2026-09-29 全区间。

## 一、结论摘要

- **整体负面观点占比（以观点条数为权重的加权平均）为 20.41%（685/3356 条观点）**；16 个议题负面占比的**简单平均为 22.84%**，差值（加权 − 简单）为 **-2.43 个百分点**，即加权值更低。
- **加权平均更能代表整体**：它等于把全部议题的负面观点与观点分别加总后相除（685 ÷ 3356），直接回答"整体用户声音里负面占多少"；简单平均把每个议题当成同等重要，让仅 1 条观点的技术原理与 717 条观点的外观与内饰拥有同等话语权。
- **差异来自议题热度与负面程度反向**：外观与内饰占全部观点条数的 21.36%（717/3356），负面占比仅 8.79%；负面占比最高的可靠性与故障（55.1%）只占观点条数的 2.92%（98/3356）。高负面的议题普遍规模小，因此简单平均被抬高。
- **简单平均对极端小样本敏感**：剔除仅 1 条观点的技术原理（负面占比 0.0%）后，简单平均升至 24.37%，与加权的差值扩大到 **-3.95 个百分点**。
- **负面观点高度集中**：空间与舒适性、安全与质量、外观与内饰合计贡献 37.96%（260/685）的负面观点，而这些议题合计覆盖 39.33%（1320/3356）的观点条数。

### 加权平均与简单平均的对照

- 以观点条数为权重加权：685 ÷ 3356 = **20.41%**。
- 16 个议题占比的简单（未加权）平均：**22.84%**。
- 差值（加权 − 简单）= **-2.43 个百分点**，加权值更低。各议题负面占比的中位数为 20.54%，与加权结果 20.41% 接近，说明加权值贴近议题分布的中间水平，而简单平均被少数高负面占比的小议题拉高。
- 敏感性：剔除仅 1 条观点的技术原理后，简单平均为 **24.37%**，差值（加权 − 简单）扩大到 **-3.95 个百分点**。

**哪个更能代表整体**：加权平均（20.41%）是"全部用户声音中负面占多少"的定义式答案，与议题热度结构一致，适合作为整体负面程度的对外口径；简单平均（22.84%）回答的是"任选一个议题，它的负面程度平均是多少"，属议题视角的分布摘要，用于议题间横向比较，但**不能替代整体负面占比**。本次两种算法方向一致——都指向负面观点不占多数，加权值 20.41% 与简单平均 22.84% 同处低负面的量级区间；但两者差值 -2.43 个百分点，对外使用必须标明取哪一种，两个数值不可互换。

### 差异成因：热度与负面程度反向

- 观点条数第一的是外观与内饰（717 条，占 21.36%），负面占比 8.79%，在 16 个议题中居后；观点条数第二、第三的是空间与舒适性（302 条，占 9.0%，负面 43.38%）与智能座舱与车机（301 条，占 8.97%，负面 7.64%）。
- 负面占比最高的两个议题规模都小：可靠性与故障 98 条（占 2.92%，负面 55.1%）、服务与交付 132 条（占 3.93%，负面 46.97%）。
- 负面观点贡献度前三位是空间与舒适性（19.12%）、安全与质量（9.64%）、外观与内饰（9.2%），其后是服务与交付（9.05%）、配置与功能（8.61%）、可靠性与故障（7.88%）。

### 精选观点样本的结构差异（口径对照）

精选观点样本共 819 条观点，其中负面 193 条，占 23.57%；与全量声明级整体负面占比 20.41% 的差值（加权 − 精选）= **-3.15 个百分点**。两者不仅在总量上不同，议题结构也不同：价格与成本在精选样本中占 11.97%（98/819），在全量中占 4.29%（144/3356）；可靠性与故障在精选样本中占 2.81%，在全量中占 2.92%。因此**精选样本的占比不能表述为全量占比**，本报告结论一律以全量声明级为准。

## 四、限制与不确定性

- **数据状态**：快照为上一版本数据（V2.3 抽取 + AUTO-018 V2 delivery-r3），占位性质，结论须带此边界，不应作为正式研究结论对外发布。
- **集合范围**："全量"仅指该冻结快照内的全部观点声明，不等同于全域舆情；精选观点样本为人工筛选后的子集，其负面占比 23.57% 高于全量的 20.41%，两者不可混用。
- **分母口径**：本报告所有占比均为声明级（负面观点条数 ÷ 观点条数），未使用帖子级分母，也未由声明级占比反推帖子级结论。
- **小样本议题**：技术原理仅 1 条观点（负面 0 条），其 0.0% 无解释力，仅按题意参与计算并在敏感性分析中单列（置信度：低，n=1）；充电与补能 64 条、其他 54 条规模也偏小，占比读数波动风险较高（置信度：中低）。
- **权重假设**：以观点条数为权重隐含"一条观点等于一份关注度"；若改用帖子数加权或按议题重要性人工加权，数值会变化。本报告未计算帖子级加权占比，因其与声明级不可互换。
- **未覆盖维度**：全量声明级指标表不含时间、用户所处阶段、车主/关注者维度，故无法在全量口径下给出整体负面占比的月度走势或分人群对照；此类分析只能在精选样本上进行，代表性有限。议题划分沿用快照既有 16 类，未重新归类。
- **证据范围**：本次分析计划未对具体议题单独立项取证，第三节引文取自精选证据中该议题的负面条目，属说明性示例，不构成该议题的统计结论。
- **共现品牌**：快照中其他品牌仅为帖子共现信息，本文未做、也不支持任何跨品牌对比结论。

## 五、待验证问题

- 整体负面占比 20.41% 是否随时间变化？需要带时间字段的全量声明级指标，或在精选样本上做月度走势并明确标注代表性限制。
- 高负面占比的小议题（可靠性与故障、服务与交付）是"问题本身更严重"还是"更易被负面表达"？需按用户所处阶段与车主/关注者身份交叉，并配合观点原文的内容归组验证。
- 若业务更关心负面反馈的帖子覆盖面而非观点条数，应另行计算帖子级负面占比（负面帖子 ÷ 帖子），与本报告的声明级数值并列呈现，两者不可相互推导。
- 外观与内饰这类高热度低负面议题的权重优势在正式快照中是否稳定？需要在非临时样本上复核后再确定对外口径。
