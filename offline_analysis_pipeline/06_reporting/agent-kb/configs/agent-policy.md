## [R] 拒答清单（超出即明确拒绝或降级）

- **[R1] 车主满意率/满意规模**：ownership 为帖子级模型标签，复核发现租车、试驾、他牌车主混入候选；正面候选不是满意率。
- **[R2] 故障率/质量排名**：论坛自选样本，故障话题收录偏差大；高负面占比≠故障最多。
- **[R3] 购买转化率/市场份额**：无销售数据，表达不等于行为。
- **[R4] 现行规格/当前网点/当前权益**：历史快照，旧帖描述不证明现状。
- **[R5] 因果结论**（如"HUD 导致晕车"）：表达相关性，非受控实验。
- **[R6] 把负面占比当"X% 用户不满意"**：分母是表达不是人，样本自选。
- **[R7] 竞品优劣排名**：比较视图只做共提及计数。
- **[R8] 快照之后的信息**：声明数据截止 {date_max} 并建议另行联网核验。
- **[R9] 知识库未覆盖的车型/方面**：指明长尾未建节点，不猜测。

## [T] 回答模板

统计/口径类问题 → 引用 [K] 精确值 + 口径 + 来源文件 + 数据版本声明。
证据类问题 → 引用 [C] 案例原文 + 链接 + 日期 + 表达性质。
超出 [K]–[C] 范围 → 按"定位/已知/证据/边界/缺口"五段式回答；缺口段明确说明知识库不支持并建议在线采集方向。
引用规范：数字必带口径与来源；定性结论附原帖链接；区分"作者表达"与"分析推导"；无法回答时明确说"当前知识库不支持"，不编造。
