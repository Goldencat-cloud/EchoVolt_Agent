# Proposal

## Why

当前工作台是"对话 + 报告"双栏切换，缺少稳定的导航结构：深度分析生成的报告只在当次会话内可见，刷新即丢；用户无法回看历史对话，也无法管理自己生成过的报告。Owner 要求参考 DeepSeek 对话网站的布局与交互风格重构工作台外壳（Owner 于 2026-10-26 提出本需求并授权实施）。

## 产品需求与产品设计

### 目标布局（参考 DeepSeek，沿用 Auto-026 品牌令牌）

- **左侧栏（三个入口，无子列表）**：
  1. 「官方报告」：点击后主区以卡片形式展示官方研究报告（含打开阅读入口）；
  2. 「我的报告」：点击后主区以卡片网格展示本浏览器保存的分析报告（可查看、可下载）；
  3. **短线分割**；
  4. 「对话历史」：直接在侧栏显示列表，最多保存 5 条记录，支持查看与切换。
- **右侧主区（卡片 + 结果视图）**：官方报告与我的报告以卡片呈现概要信息；新增报告结果视图，清晰呈现报告结构（标题、状态、数据版本、关键结论、正文分节）与关键信息；深度分析完成后自动展示并保存到「我的报告」。
- **报告下载**：结果视图提供下载（Markdown 文件）。
- **响应式**：桌面端侧栏常驻；移动端（<1024px）侧栏抽屉化 + 遮罩。

### 本 Change 不做

- 不改任何 API 行为、报告生成与发布链路（沿用 auto-023/025/028 既有接口）。
- 不改官方报告内容与样式（`report-skin.css` 不动）。
- 我的报告与对话历史仅保存在浏览器 localStorage（演示场景，无多端同步需求）。

## What Changes

- 重构工作台外壳为"侧栏 + 主区"结构：侧栏含官方报告、我的报告、分割线、对话历史（≤5 条）。
- 新增结果视图：结构化展示深度分析报告（标题/状态/数据版本/关键结论/正文），支持下载为 Markdown，并自动存入「我的报告」。
- 对话历史持久化：最近 5 条会话保存于 localStorage，可查看与切换；新建对话入列。
- 修复现有缺陷：实时报告状态元素 `#doc-status` 缺失导致生成过程中状态更新抛错。

## Capabilities

### New Capabilities

- `workspace-navigation`：约束工作台侧栏分区、对话历史、我的报告与结果视图的可观察行为。

## Impact

- 修改 `08_semantic_services/web/`（index.html / app.js / styles.css / tokens.css）；不改任何 Python 后端、API 与报告发布逻辑。
- 与 auto-026 共享设计令牌（夜航蓝/电光蓝/香槟金），不引入 UI 框架。
