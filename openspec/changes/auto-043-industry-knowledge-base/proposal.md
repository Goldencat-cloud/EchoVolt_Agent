# Proposal

- **Change ID**: `auto-043-industry-knowledge-base`
- **Human Owner**: 待指派（本变更在 Owner 指定并完成规格评审前不得进入业务实现）
- **规格评审状态**: 待评审（reviewer、日期、reviewed commit、结论均未产生）
- **阶段**: 规划（本变更只产出规格与设计，不含实现）

## Why

Agent 目前只有两类证据：内部论坛快照（语义层，仅覆盖小米 SU7）与内部已发布报告。外部行业知识为零，且缺口已被现有产物自己记录：

- 设计版报告「使用边界」明确列出不能回答项：真实车主满意度、产品故障率、**现行产品规格与服务网络现状**、**竞品优劣排名**、政策与市场（`06_reporting/agent-kb/output/report.md`、`content.json:140`）。
- 语义模型中 `政策与市场` 与 `无法判断` 被 `excluded`（`semantic/model.yaml:159`），政策类问题在数据结构层面就无法回答。
- 术语层只有内部字段到用户话术的对照（`terminology.py:4-40`），没有汽车行业术语定义。
- `agent_skills/report-authoring/reference/build-argument.md` 要求归因四要素，示例本身依赖"产能爬坡与竞品促销"这类外部事实，但链路中没有任何来源提供它。
- `06_reporting` 的 F4 只能证明"用户拿 Model 3 与极氪 001/007 做参照"（Model 3 关联提及 201 帖），无法给出这些车的客观参数，因此对比矩阵只能停在"谁被比较"。

`modules/external_events` 虽有外部检索能力，但它是独立 MCP 进程、未在 `kernel/registry.py` 登记，Agent 无法调用；其工具层实测（`outputs/eval/tool_quality_eval.json`）为召回 34.1%、事件精确率 81.2%、聚类纯度 68.6%、0 例捏造——失败模式集中在来源污染与覆盖不全，而非生成失真。

现在做的理由：**先建立只收可证官方来源的窄入口，比事后在检索结果里修污染便宜**。本变更把"外部知识"限制为一个可审计的只读证据层，不改变内部数据的口径与权威性。

## What Changes

- **新增模块** `offline_analysis_pipeline/09_industry_kb/`：离线建库 + 运行期只读检索，不改动 01–08 任一模块的产物与业务逻辑。
- **来源准入白名单（只做官方来源）**：仅接受部委与标准化机构官方发布（`gov.cn` 及部委站点、`samr.gov.cn`）与厂商官方发布；明确禁止 UGC、垂直媒体参数页抓取（汽车之家用户协议禁止"抓取页面/机器人/蜘蛛"）、商业研报全文转载。`external_events` 的 `t2_domains`（门户与垂直媒体）**不作为**本库来源。
- **字段准入（只做可证字段）**：竞品参数仅收录工信部《减免车辆购置税的新能源汽车车型目录》附件可复核字段——纯电续驶里程（含 CLTC 标注）、整车整备质量、动力蓄电池组总质量、动力蓄电池组总能量、产品类别；**不收录指导价、智驾硬件、座舱配置**等无第三方可证来源的字段。
- **新增双层知识模型**：`document`（术语、政策解读，标题切片）与 `fact`（参数与政策条款，字段级，带 `as_of`、`batch`、`status`、`effective_from/effective_to`）。可结构化的事实不进检索语料，避免检索片段被当成数字来源。
- **新增单一检索协议** `search_industry_kb(question, categories, as_of, top_k)`：返回片段 + 事实 + 覆盖声明 + 降级告警 + 可校验引用；FTS5 三元组召回为主，配置 embedding 时混合打分，未配置时显式降级（沿用 `research/service.py` 既有语义）。
- **新增独立引用命名空间** `[KB-<doc_id>#<chunk>]`：与数字锚点 `[K]` 严格分离，报告门禁新增校验——外部事实断言必须带 KB 引用、发布方与日期，缺失即降级为背景说明或拒答。
- **新增冲突规则**：外部知识与内部统计冲突时以内部数据为准；外部只能解释与补充背景，不得覆盖统计结论，跨源不一致必须写入「限制与不确定性」。
- **新增 Agent 接入面**：`kernel/registry.py` 登记只读工具、`kernel/profile.py` 白名单（交互与交付两种姿态分别评估）、`integrations/mcp_server.py` 只读暴露。
- **不改变**：语义层口径与指标、内部数据表结构、已有报告结构与结论、HTTP 既有路径、审核发布流程；**不引入新运行时依赖**（沿用标准库 + `openai` 既有 embeddings 客户端）。

### 明确排除（Out of Scope）

1. **销量与价格明细**：公开渠道只能到行业大盘与品牌级叙述，车型级明细属付费数据；首批不收录，避免与内部帖量口径混用。
2. **质量投诉数据**（车质网等）：与内部 `negativeShare` 语义重叠，混用会重演 auto-039 记录的两级口径错误；本变更不引入。
3. **竞品优劣结论**：只提供客观可证参数，不产出排名、评分或推荐结论。
4. **运行期联网**：不在 Agent 运行时抓取或检索网络，`prompts.py` 的"只能用语义层数据、代码禁 import/IO"硬约束不放宽；采集只发生在离线建库。
5. **不重新运行**抽取、归一、报告构建链路，不修改 01/04/05/06 产物。
6. **不写入** `openspec/specs/`，不归档任何在建变更。

## Capabilities

### New Capabilities

- `industry-knowledge-corpus`: 外部行业知识的来源准入、内容分层（document / fact）、强制元数据（发布方、发布日、获取日、来源等级、许可、批次、效力状态）、可证字段边界、时效与失效处理、离线构建产物与校验。
- `industry-knowledge-retrieval`: 检索协议与响应信封——中英混合召回、双层结果合并、覆盖与降级披露、引用标识生成、时效过滤、内部数据冲突时以内部为准的裁决规则。
- `agent-external-evidence`: Agent 侧使用约束——工具登记与 profile 白名单、MCP 只读暴露、报告门禁对 KB 引用的校验、外部断言的表述边界（不得覆盖统计结论、不得产出竞品排名）。

### Modified Capabilities

无。当前 `openspec/specs/` 为空，没有已存在的正式能力需要变更。

## Impact

- **新增代码**：`offline_analysis_pipeline/09_industry_kb/`（`corpus/`、`build/`、`query/`、`tools/`、`eval/`、`tests/`）、`domains/automotive/model.yaml`。
- **新增数据**：`09_industry_kb/data/kb.sqlite3`（document/chunk/fact + FTS5 索引）、`corpus-manifest.json`（来源清单与哈希）、`data-version.json`。
- **受影响的下游（接线阶段）**：`08_semantic_services/kernel/registry.py`（工具登记与能力标签）、`kernel/profile.py`（白名单）、`agent_tools.py`（工具声明与 docstring）、`report_gate.py`（KB 引用校验）、`integrations/mcp_server.py`（只读工具）、`terminology.py`（术语来源改为引用 KB 而非硬编码）。
- **并行约束**：`auto-039`（语义层）、`auto-042`（架构整合）正在改动 `kernel/`、`report_gate.py`、`agent_tools.py` 周边；本变更新增文件为主，接线须由 Owner 决定顺序并避免同文件双写。
- **首批内容**：源文件约 22 份，入库以条目计——术语 9 条（续航能耗 4 条、智驾 3 条、分类与充电 2 条，来源为 GB/T 19596-2017、GB/T 38146.1-2019、GB/T 3730.1-2022、GB/T 44373-2024、GB/T 39263-2020、GB/T 40429-2021、GB/T 29317-2021；整备质量因标准全文受版权限制改用工信部目录申报口径；"800V 平台""交付爬坡"等无标准定义的行业口语不进入标准层）、政策 11 项（政策文件 6 份 + 目录公告 1 份仅登记来源与附件地址 + 强制国标 4 份，全部核到官方原文，含批次、发文字号与效力状态；上位总纲只记文号不入库；带「本文有删减」标注的以旧换新细则不收录）、参数 1 份目录附件覆盖 5 组车型（小米 SU7、特斯拉 Model 3、极氪 001/007 等，仅工信部可证字段）。
- **风险**：
  1. 政策批次高频更新（已到第三十三批，2026-08），若缺 `status` 与有效期会产出过期权威知识。
  2. 工信部目录附件为 `.doc` 表格，解析质量决定事实层可靠性；需逐批次核对行数与字段完整性。
  3. 内部数据与外部参数混排时可能被读成同一口径；必须在渲染层强制标注来源与日期。
  4. 只收官方来源会显著限制覆盖面（无价格、无智驾配置、无车型级销量），该限制需在检索响应与报告中显式披露，而非由模型自行补全。
