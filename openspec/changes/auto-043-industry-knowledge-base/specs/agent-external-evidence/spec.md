# Spec Delta

## Purpose

约束 Agent 如何使用外部行业知识：只能通过登记过的只读工具获取，只能在带来源与日期的前提下引用，且不得用外部知识覆盖内部统计结论或派生竞品排名。

## ADDED Requirements

### Requirement: 工具登记与可见性

外部知识检索 SHALL 作为独立只读工具登记在工具清单中，并使用独立能力类别，不得并入既有读能力类别。未登记的工具有效不可用；每个 Profile MUST 显式包含该能力类别，方可调用该工具。

新增工具 MUST NOT 因能力类别展开逻辑而自动获得既有姿态的权限。

#### Scenario: 交互姿态可用
- **WHEN** 用户提问"CLTC 是什么意思"
- **THEN** 交互链路可调用外部知识工具并返回带引用的释义

#### Scenario: 未加入白名单
- **WHEN** 某 Profile 的能力白名单未包含外部知识能力类别
- **THEN** 装配期校验失败或该工具对模型不可见，MUST NOT 在运行期才暴露

#### Scenario: 新增能力不扩大既有姿态
- **WHEN** 引入新的能力类别登记表
- **THEN** 既有 Profile 的可用工具集合保持不变，除非该 Profile 显式加入新类别

### Requirement: 只读边界

外部知识能力 SHALL 只读。MUST NOT 通过该能力写入、发布、归档知识条目，MUST NOT 暴露任意 SQL、文件系统访问或运行期联网。

#### Scenario: 尝试写入
- **WHEN** 请求包含新增或修改知识条目的意图
- **THEN** 系统拒绝并说明知识库仅支持离线构建

#### Scenario: 运行期联网
- **WHEN** Agent 需要知识库未收录的信息
- **THEN** 系统返回未收录声明，MUST NOT 发起网络请求补全

### Requirement: 外部断言的引用义务

报告中任何来自外部知识的陈述 SHALL 附带可校验引用标识、发布方与发布日期。缺失任一者的外部断言 MUST 被门禁拦截或降级为背景说明。

#### Scenario: 合规引用
- **WHEN** 报告写明"某车型整备质量为 X，据工信部某批次目录"
- **THEN** 门禁校验引用存在于本次检索结果、发布方与日期在场，通过

#### Scenario: 无来源断言
- **WHEN** 报告出现"行业普遍认为…"但无可校验引用
- **THEN** 门禁判定为外部断言缺证，要求补引用或改为背景说明

### Requirement: 不得覆盖内部统计结论

外部知识 SHALL 只用于解释、补充背景与对照，MUST NOT 改变、替换或重新解释内部统计数据与由此得出的结论。

#### Scenario: 外部数据与内部结论冲突
- **WHEN** 外部参数或政策口径与内部统计结论不一致
- **THEN** 报告保留内部结论并注明外部口径差异，冲突写入「限制与不确定性」

#### Scenario: 用外部数据改写结论
- **WHEN** 报告用外部数值替换内部统计值或推断出新的统计结论
- **THEN** 门禁判定失败

### Requirement: 禁止派生竞品排名

外部知识 SHALL 只提供客观可证字段。MUST NOT 基于外部字段计算综合评分、排名、推荐或优劣结论。

#### Scenario: 请求竞品排名
- **WHEN** 用户要求"这几款车哪个更好"
- **THEN** 系统给出可比字段与口径差异，声明不提供排名或推荐

#### Scenario: 报告中出现评分
- **WHEN** 报告用外部参数构造加权评分或排序表
- **THEN** 门禁判定失败并提示改为字段对照

### Requirement: 引用命名空间隔离

外部引用 SHALL 使用与内部数字锚点不同的标识前缀，并在渲染层区分来源标记。MUST NOT 让外部引用被解析为内部数据锚点。

#### Scenario: 混合引用
- **WHEN** 同一段落同时引用内部统计与外部参数
- **THEN** 两类引用分别渲染且指向不同来源，读者可区分

#### Scenario: 前缀冲突
- **WHEN** 外部引用使用了内部锚点前缀
- **THEN** 校验报错并要求改用外部前缀

### Requirement: 覆盖限制的显式表达

当问题需要知识库未收录的内容（价格、智驾配置、车型级销量、投诉）时，Agent SHALL 明确说明未收录，并给出可回答范围，MUST NOT 依赖模型记忆补全。

#### Scenario: 询问未收录字段
- **WHEN** 用户询问某车型指导价
- **THEN** 回答说明价格类字段未纳入知识库，可提供续航与电池等可证字段

#### Scenario: 模型记忆补全
- **WHEN** 回答包含知识库中不存在且无引用的具体数值
- **THEN** 门禁判定为无来源断言
