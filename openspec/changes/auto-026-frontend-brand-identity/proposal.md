# Proposal

## Why

当前前端视觉是多次临时叠加的结果：没有品牌定位、没有设计令牌，色调/字号/文案各自为政，用户（Owner）明确反馈"没有品牌感、没有设计"。比赛演示场景下，界面可信度直接影响评委对产品专业度的判断。

## 产品需求与产品设计

### 品牌定位（Owner 已批准）

**AutoInsight · 新能源洞察工作台** —— "实验室里的研究报告"。

- 面向新能源汽车用户研究的对话式分析智能体；一切结论可复核、可回溯。
- 品牌人格：**证据驱动、精确克制、仪器感**。科技感来自秩序与数据密度，而非霓虹特效。
- 双材质策略：左侧"工作台/仪器"（冷色、精密、发光强调），右侧"文献/纸面"（暖纸、衬线、编辑部排版）——研究在左发生，结论在右沉淀。

完整设计系统（色彩、字体、布局、组件、文案）见本 Change `design.md`。

### MVP 范围

- 设计令牌（CSS 变量）化：色彩、字号、间距、圆角、阴影、动效统一收敛。
- 工作台外壳与对话组件按新令牌重做；报告内容沿用 auto-023 研究结构，嵌入报告与工作台共享品牌令牌、版本/口径标识和证据链接样式。
- 文案梳理：品牌命名、固定术语表、错误文案三段式规范落地。

### 本 Change 不做

- 不改报告数据与结论生成逻辑；可调整报告外观以与工作台一致，不动 API 行为与数据链路。
- 不引入 UI 框架/构建工具链（保持 stdlib + 原生三件套）。
- 不做暗色主题与多主题切换（后续版本再议）。

## What Changes

- 建立品牌设计系统文档与 CSS 设计令牌，替换现有叠加式样式。
- 按"仪器感"重做工作台外壳：顶栏、对话流、气泡、输入区、分隔条。
- 建立品牌文案规范：术语口径固定、语气克制、错误信息三段式。

## Capabilities

### New Capabilities

- `product-identity`：约束产品品牌视觉一致性、文案术语口径、分析流程与双材质布局的可观察行为。

### Modified Capabilities

- `report-orchestration`：增加工作台与嵌入报告的共享身份、分析维度、口径与证据展示要求。

## Impact

- 修改 `08_semantic_services/web/` 前端资源及嵌入报告样式入口；不改报告数据、结论或 API 行为。
- Owner 于 2026-10-25 明确要求与 Auto-025 同工作区顺序集成共享 Web 文件，授权该实施顺序。
