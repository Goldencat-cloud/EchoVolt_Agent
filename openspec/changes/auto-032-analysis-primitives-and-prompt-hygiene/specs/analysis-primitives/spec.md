# Spec Delta

## Purpose

为深度分析提供受限的声明式聚合表达能力：在不引入自由 SQL、不削弱确定性校验与溯源的前提下，让分析覆盖时间切片、跨维度交叉与对比，并使计划校验与前端表单选项同源于分析能力声明，消除"UI 承诺引擎无法兑现"的失信点。

## ADDED Requirements

### Requirement: 受限参数化聚合原语

系统 SHALL 为 Agent 提供一个受限的声明式聚合原语：Agent 只能声明指标（metric，取值来自版本化指标目录）、分组维度（group_by，取值来自已登记维度）与过滤条件（filter，取值来自任务简报枚举或覆盖声明）；系统 MUST 拒绝任何目录之外的取值，并以确定性方式构造只触及语义层视图的查询。Agent MUST NOT 能够通过该原语提交自由 SQL 或目录之外的维度、枚举值。

#### Scenario: 合法原语调用返回可验证结果

- **WHEN** Agent 以目录内的 metric、group_by 与合法过滤值调用聚合原语
- **THEN** 系统返回数据行、口径说明与校验状态，且结果登记进溯源账本（与白名单方法同级，可进入报告）

#### Scenario: 目录外取值被拒绝且不消耗重复失败

- **WHEN** Agent 声明了目录外的 group_by、metric 或不在快照枚举内的过滤值
- **THEN** 系统拒绝该调用并返回具体允许值清单，该调用按工具错误预算计数

### Requirement: 原语结果的口径与复核

每个原语结果 SHALL 携带口径声明（全量声明级 / 精选子集），且 MUST 通过与白名单方法同级的确定性复核（关键比例从原始计数复算、计数与快照核对）后才可被报告引用；复核失败或结果为空的处置 MUST 与现有白名单方法一致（空结果登记、不得引用其数字）。

#### Scenario: 复算不符的结果不可引用

- **WHEN** 原语结果中的占比与其分子分母复算不符
- **THEN** 系统判定校验失败并拒绝登记该步骤，Agent 不得在报告中引用该结果

#### Scenario: 空结果如实登记

- **WHEN** 原语查询合法但结果为空（如所选时间区间内无声明）
- **THEN** 系统登记为空结果步骤，Agent 须在报告"限制与不确定性"章节说明，不得引用该结果数字

### Requirement: 时间切片过滤

聚合原语 SHALL 支持日期区间过滤：过滤后的统计 MUST 仅包含区间内的观点声明，且区间 MUST 落在冻结快照覆盖范围内，超出范围 MUST 被拒绝并返回允许区间。

#### Scenario: 时间切片统计只含区间内声明

- **WHEN** Agent 以"近 3 月"对应的日期区间对议题执行负面占比聚合
- **THEN** 返回结果的计数仅统计该区间内的观点声明，口径说明注明时间范围

#### Scenario: 超出快照覆盖范围的区间被拒绝

- **WHEN** Agent 声明的日期区间早于或晚于快照覆盖范围
- **THEN** 系统拒绝该调用并返回快照允许的区间

### Requirement: 跨维度交叉分析

聚合原语 SHALL 支持在已登记维度内组合最多两个维度进行交叉分组（如情感×用户阶段），交叉结果的每个单元格计数 SHALL 继承所选过滤条件的口径；精选子集维度的交叉结果 MUST 标注精选子集边界。

#### Scenario: 交叉分组返回组合计数

- **WHEN** Agent 对单一议题以"情感×用户阶段"执行交叉聚合
- **THEN** 系统返回各组合的计数行，口径标注为精选子集（该维度归属精选子集时）

### Requirement: 计划校验瘦身后服务端推导

分析计划 MUST NOT 要求模型填写可由 method 推导的字段：维度合法性由 method→维度映射在服务端判定，证据需求由 method 语义在服务端推导；服务端在计划批准后 MUST 按推导结果强制执行（需要证据的工作项未取得带 claim_id 证据时报告提交仍被拒绝）。计划接口 MUST 向后兼容：旧计划包含被移除字段时服务端忽略之，不拒绝。

#### Scenario: 不含可推导字段的计划获批

- **WHEN** Agent 提交仅含子问题、method、aspect 与可选可视化意图的计划草案
- **THEN** 系统完成维度合法性与证据需求推导并批准计划，执行与报告门禁行为不变

#### Scenario: 旧字段计划向后兼容

- **WHEN** Agent 提交包含 dimension 或 requires_evidence 字段的计划草案
- **THEN** 系统忽略这些字段并按服务端推导结果处理，不因字段存在而拒绝

### Requirement: 纯量化分析报告不强制观点引用

当已批准计划中不存在需要证据的工作项（由 method 推导）时，报告门禁 MUST NOT 因报告未引用观点证据（claim_id）而拒绝提交；该情形 SHALL 降级为提示。计划中存在需要证据的工作项时，提交门禁仍 MUST 强制其取得并引用带 claim_id 的证据。

#### Scenario: 纯量化计划报告通过提交门禁

- **WHEN** 计划全部工作项均由服务端推导为无需证据，报告完成全部工作项且未引用观点原文
- **THEN** 提交门禁不因缺少观点引用而拒绝（可有提示），报告进入待审

#### Scenario: 需证据工作项仍强制引用

- **WHEN** 计划含推导为需证据的工作项
- **THEN** 未取得带 claim_id 证据或正文未引用时，提交仍被拒绝

### Requirement: 数字溯源的判定边界

数字溯源 SHALL 仅从已验证步骤的结果数据（结果行、代码分析输出、图表数据、证据记录）提取可比数字，MUST NOT 将查询元数据（SQL 文本、耗时、行数、参数回显）计入可比来源。报告中的叙述性数字（日期的月日、序数"第 N"及量词化小整数等）SHALL 有明确清洗或白名单规则；展示舍入 SHALL 被接受——报告带小数点的数值 SHALL 等于源数值按报告小数位数四舍五入后的结果，否则拒绝（整数计数保持逐字一致）。

#### Scenario: 源元数据数字不再充当溯源依据

- **WHEN** 报告引用的数字仅存在于工具结果的 SQL 文本或耗时字段
- **THEN** 该数字被判定为未溯源并拒绝

#### Scenario: 展示舍入被接受

- **WHEN** 源数值为 0.203125，报告写 0.2（或 20.3%）
- **THEN** 数字溯源通过；报告写 0.24 仍被拒绝

### Requirement: 空结果解释判定的鲁棒性

空结果须在限制章节解释的判定 SHALL 满足：限制章节包含议题名，或包含明确的"无数据"类表述（空/无数据/未返回/不支持/未覆盖）之一；全表空结果（无议题名）SHALL 以"限制章节非空且提及该方法"替代议题名匹配。判定 MUST NOT 存在任何表述都无法通过的死锁路径。

#### Scenario: 同义表述被接受

- **WHEN** 限制章节写明某议题"未返回结果"
- **THEN** 该空结果视为已解释，不阻断提交

#### Scenario: 全表空结果可解释

- **WHEN** 全表空结果步骤无议题名，限制章节非空且提及该方法名
- **THEN** 提交不被阻断

### Requirement: 表单选项由能力声明同源生成

深度分析表单选项端点 SHALL 由聚合原语的能力声明推导生成时间范围切片与对比选项：原语能力声明支持日期区间过滤后，对应时间切片选项才可展示；能力未声明时对应选项 MUST NOT 出现在返回结构中。选项目录与 Agent 任务简报 MUST 同源生成，不得出现两处不一致。

#### Scenario: 已声明能力如实开放选项

- **WHEN** 聚合原语的能力声明包含日期区间过滤
- **THEN** `/api/analysis/options` 返回时间范围切片选项，且其区间与快照覆盖范围一致

#### Scenario: 未声明能力不在 UI 承诺

- **WHEN** 某分析能力（如跨品牌对比）未在能力声明中开放
- **THEN** 表单选项不返回该能力对应的选项，用户无法选择引擎无法执行的分析
