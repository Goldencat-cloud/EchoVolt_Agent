## 数据依赖与口径来源

- 全部数字抄录自冻结文件：`analysis/summary.json`（cohort、evidence_checks、ownership、core_sentiments、时间范围）、`analysis/profiles.json`（6 个 cohort 的方面×情感）、`analysis/aspect-sentiment.csv`（产品体验或风险集）、`analysis/scope.json`（竞品白名单与提及计数）、`analysis/reviewed-cases.json`（11 案例）、`analysis/verification.json`（12 项检查）。
- 上游口径沿用 V2.3 抽取 + AUTO-018 V2 delivery-r3 映射；报告不引入新计算引擎。报告中的派生值（cohort 保留率、旅程对比行）在文中标注"派生"。

## 关键设计决策

0. **数据版本边界与可替换性（Owner 2026-10-22 指示：只搭架子）**：当前 `analysis/` 数据是上一版本产物，新版本待队友完成。因此本 Change 交付的报告是**结构验证样例/占位知识库**：数字只用于验证报告结构与口径写法，不代表正式结论；沉淀数据契约（来源文件清单 + 版本声明 + 每文件职责），Agent 侧后续 MUST 通过数据层读取数字而非硬编码。新数据就位后按同一契约整体替换，报告章节结构与 Agent 行为约束不变。
0a. **双读者格式与可插拔模板（Owner 2026-10-22 确认）**：单一 Markdown 源（`agent-kb/report.md`）+ `build_report.py` 从 `analysis/*.json` 生成的 SVG 图表与 `data-version.json` 版本清单 + `export_html.py` 导出的单文件 HTML（图片内嵌 base64，离线双击可看）。分工：图表与排版给人，caption 数字锚点与 §3/§10/§11 结构给 Agent；Copilot 问答以章节锚点（"§5.1 图2"）定位，超出报告范围的问题按五段式第⑤段转在线分析。模板与数据层分离：新版本数据就位后重跑两个脚本即可整体换血，章节结构与契约不变。图表用手写 SVG（stdlib-only，git 可 diff），禁止手贴截图。

1. **临时版定位**（Owner 指示跳过离线评估）：报告正文不含评估结论，仅在升级路线中预留接入点；报告与 OpenSpec 工件均显式标注 PENDING_REVIEW / 临时，不冒充验收交付。
2. **面向机器消费的结构化重组**：与叙事型 `SU7需求分析报告.md` 并存而非替代；新增术语表（含常见误用列）、拒答清单、五段式回答模板、阅读指南——这四者是 Agent 问答与在线分析的直接接口。
3. **诚实边界**：沿用既有报告结论——ownership 为帖子级模型标签、复核发现租车/试驾/他牌车主混入候选，因此不输出车主满意率；负面占比是表达口径不是人数口径。
4. **数字策略**：只抄录冻结文件数值 + 少量标注过的派生比值；不重跑 analyze.py（其输出目录约定不可覆盖），不新增任何模型调用。

## 已核验事实 vs 假设

- **已核验**：初稿全部数字在撰写时从冻结 JSON/CSV 直接抄录核对；上游 12 项检查通过（verification.json）。
- **版本限制**：以上核验针对**上一版本数据**；新版本数据就位后所有数字须按数据契约重新生成与复核，本版数字自动失效为占位。
- **假设/待办**：报告的行文结构是否满足 Agent 检索需求，待 Owner 评审；数字的独立第三方抽查尚未执行（列为任务）。
- **不可用检查**：人类语义准确率未测量（沿承上游声明）；本 Change 不补测。

## 与后续 Change 的接口预留

- **阶段路线（Owner 2026-10-22 确认）**：
  - 第一阶段 = 本 Change（报告 + 数据接缝）+ 问答 Agent Change（报告问答 + 明细即时查询 + 缺口日志；联网采集分析不做）；
  - 第二阶段 = Agent 团队自动产出与核查报告 Change（起草 agent / 审查 agent / 分级发布 gate；数据管道自动跑、报告更新由 agent 承担；人只处理异常与结论翻转）；
  - 第三阶段（视缺口日志）= 联网补充分析，走 01_ingestion 完整许可流程。
- **无人值守分级发布原则**（第二阶段实现依据，本 Change 的结构为其预留）：数字/图表/Agent 版 = 确定性内容自动发布；规则可验证的结论句 = 机器证明后自动发布；状态翻转的结论 = 降级措辞或挂起待审。任何结论可回溯到数据层证据。
- **自动化边界**：凡可写成无歧义规则的→机器；需判断的→AI 起草 + 人批准；分析设计（问题定义/口径/优先级）→ 人定、写成文档长期复用。
- 问答 Agent Change：以 Agent 版 MD 的 [K]/[D]/[R]/[T] 锚点为行为约束输入，消费 numbers.json 与明细索引；缺口日志作为后续报告版本的需求输入。
- 离线评估 Change 完成后：其结论按升级路线接入，报告升级为正式版。
