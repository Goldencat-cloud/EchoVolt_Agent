# Spec Delta

## Purpose

定义临时离线分析报告作为 Agent 知识库的契约：报告中的每个数字可追溯、口径先于数据、边界显式可拒答、面向 Agent 消费结构化组织，且不与未完成的离线评估或其他 Change 的产出混淆。

## ADDED Requirements

### Requirement: 数字可追溯
报告中的每个统计数字 SHALL 可定位到 `06_reporting/analysis/` 冻结文件的对应字段或文中标注的派生计算。报告 MUST NOT 引入无法追溯的数字，MUST NOT 修改冻结数据文件。

#### Scenario: 抽查统计数字
- **WHEN** 评审者对报告中任一精确计数（如舒适性负面 131 条）要求溯源
- **THEN** 报告标注的来源文件中存在相同数值，且口径（筛选集）一致

#### Scenario: 派生比值
- **WHEN** 报告给出冻结文件中不直接存在的比值（如 cohort 保留率 55.7%）
- **THEN** 该值在文中被标注为派生，且可由已标注的两个来源数值复算

### Requirement: 数据版本声明与可替换性
报告与知识库 SHALL 声明其数据版本、来源文件清单及占位性质。报告 MUST NOT 被当作新版本数据的正式结论；后续 Agent 架子 MUST 通过数据层读取统计数字，MUST NOT 在代码或提示词中硬编码具体数值。新版本数据就位后 SHALL 能按同一数据契约整体替换，而不改变报告章节结构与 Agent 行为约束。

#### Scenario: 新版本数据替换
- **WHEN** 队友交付新版本分析数据，其文件符合知识库数据契约（来源清单 + 版本声明）
- **THEN** 可整体替换报告数据层并重新生成数字，报告结构、口径术语表、拒答清单与回答模板保持不变，Agent 代码无需修改

#### Scenario: 数字硬编码检查
- **WHEN** 检查后续 Agent 的实现代码或提示词
- **THEN** 不存在写死的具体统计数字；所有计数与占比来自知识库数据层并在回答中随数据版本声明

### Requirement: 双读者双投影结构
报告 SHALL 以两份结构各自独立优化的成品交付：`report.html` 面向人类（叙事流、图文交互、结论先行、落地建议），`report.md` 面向 Agent（扁平自包含段落、核心数字速查、口径/拒答/模板策略块）。两份成品 MUST 由同一数据层经渲染脚本生成，MUST NOT 手写内容重复的平行文档。Agent 版 MUST 以机器可检索方式组织（每段自包含、锚点明确、含拒答清单与回答模板）。HTML SHALL 提供基础交互（目录导航、图表视图切换、案例筛选、附录折叠），MUST 离线可打开且不依赖外部网络资源。

#### Scenario: 人类阅读与 Copilot 伴随问答
- **WHEN** 人类在 HTML 视图中阅读报告并向 Copilot 提问报告内已有内容
- **THEN** Copilot 从 `report.md` 检索作答，给出章节锚点，且锚点引用的数字与数据层一致

#### Scenario: 双格式数字一致
- **WHEN** 对同一数据版本渲染两份成品
- **THEN** verify 校验确认 HTML 与 MD 中的关键统计数字一致，且全部数字可回溯到答案册（numbers.json）

### Requirement: 数据可替换与可扩展
报告生成链 SHALL 以答案册（numbers.json）为唯一数据接缝：渲染成品 MUST 不直接读取上游数据文件，全部统计数字经答案册注入。新增分析维度 SHALL 通过"生成函数 + 模板槽位"扩展，不要求修改渲染器核心。上游数据文件变更时，构建 MUST 先经入场校验，不一致时精确报错并拒绝出图，MUST NOT 以缺失字段静默产出错误数字。

#### Scenario: 新版本数据整体替换
- **WHEN** 队友交付新版本分析数据
- **THEN** 重跑构建链即可重新生成图表、答案册与两份成品；人只需复核叙述性结论，无需修改渲染代码

#### Scenario: 上游字段变化被拦截
- **WHEN** 新数据的必需字段缺失或类型不符
- **THEN** 构建报错并指明具体字段，不生成任何成品

### Requirement: 口径与术语先行
报告 SHALL 在展示统计数字之前定义核心口径与术语（Claim/表达、帖、提及、cohort、负面占比、引文检查、ownership），并 SHALL 对每个口径给出常见误用警示。表达数 MUST NOT 被表述为人数。

#### Scenario: 负面占比提问
- **WHEN** 报告陈述"空间与舒适性负面占比 43.4%"
- **THEN** 术语表已定义该比值的分母为该方面全部表达（含中性/混合），且明确其不是负面人数比例或满意度

### Requirement: 边界显式可拒答
报告 SHALL 包含明确的禁止结论清单（拒答边界），覆盖满意度、故障率、转化率、现行规格、因果结论、竞品优劣排名等不支持的外推。超出快照时间范围的问题 SHALL 提示数据截止时间。

#### Scenario: 询问车主满意率
- **WHEN** Agent 被问"SU7 车主的满意率是多少"
- **THEN** 依据报告边界条目拒绝输出满意率，并可说明 ownership 标签复核发现租车/试驾/他牌车主混入候选的事实依据

#### Scenario: 询问快照之后的信息
- **WHEN** 用户询问 2026-10-03 之后的现状（现行网点、权益、规格）
- **THEN** Agent 声明数据为历史快照并建议另行核验，不将旧帖描述当作现行事实

### Requirement: Agent 消费结构
报告 SHALL 提供面向 Agent 的阅读指南（按用例导航）、可回答问题类型分类及回答模板（定位/已知/证据/边界/缺口五段式）。证据案例 SHALL 附原帖链接、日期、表达性质与证据边界。

#### Scenario: 引用证据案例
- **WHEN** Agent 回答中引用某条用户表达
- **THEN** 回答附带原帖链接与日期，并区分"作者表达"与"分析推导"，不把推导伪装为作者原意

### Requirement: 范围隔离与临时声明
报告 MUST NOT 包含未完成的离线评估结论，MUST NOT 声称已验收或可公开。报告 SHALL 声明其临时定位、数据版本与所在分支。本 Change MUST NOT 修改 auto-022 的代码、标注表或别名映射，MUST NOT 修改 `06_reporting/analysis/` 冻结文件。

#### Scenario: 与清洗 Change 隔离
- **WHEN** 检查本 Change 分支的变更文件清单
- **THEN** 仅包含报告文档与 `openspec/changes/auto-023-temp-analysis-report/` 工件，不含 02_cleaning 或 analysis/ 冻结数据的改动

#### Scenario: 评估结论接入
- **WHEN** 离线评估 Change 尚未交付
- **THEN** 报告不含任何评估结论，仅在升级路线中说明其未来接入点
