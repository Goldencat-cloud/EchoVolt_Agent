# Spec Delta

## Purpose

定义对话内轻量分析的行为契约：作为"行研机构"产品中对话 Agent 的隐式分析能力，覆盖报告问答、确定性统计与观点证据下钻，显式引用报告通过斜杠命令完成；同时约束其边界——不执行生成式代码、不产出报告文件，分析诉求一律引导至深度分析入口。

## ADDED Requirements

### Requirement: 轻量分析能力边界

对话 Agent SHALL 在普通对话中按需隐式执行轻量分析，可用能力 SHALL 限定为：官方报告与我的报告全文问答、语义层确定性统计查询（`semantic_*` 视图）与观点证据下钻。对话 Agent MUST NOT 调用代码解释器，MUST NOT 产出报告文件，MUST NOT 将轻量分析结果保存为报告。回答 SHALL 附带数据口径与来源。

#### Scenario: 自然对话中的数据小问题

- **WHEN** 用户在对话中询问"比亚迪和特斯拉哪个口碑更好"且预置统计可回答
- **THEN** Agent 按需调用统计查询或报告检索，在对话内直接给出带口径与引用的回答，不生成任何报告文件

#### Scenario: 预置统计无法回答

- **WHEN** 用户的问题需要跨维度的开放式分组分析且预置统计不能直接回答
- **THEN** Agent 说明当前对话内无法完成该分析，引导用户点击"深度分析"按钮发起正式分析，不调用代码解释器

### Requirement: 分析诉求的意图引导

对话 Agent SHALL 识别用户消息中的分析诉求（如"帮我分析一下X""出一份关于X的报告"），且 MUST NOT 在对话内执行该诉求；SHALL 引导用户使用"深度分析"按钮，说明深度分析将提供主题澄清、大纲审查与正式报告。

#### Scenario: 用户直接要求写报告

- **WHEN** 用户在对话输入"帮我写一份新能源用户口碑分析报告"
- **THEN** Agent 不执行分析、不产出报告，回复引导内容并指引用户点击"深度分析"按钮

#### Scenario: 寒暄与能力询问不误触发

- **WHEN** 用户问候、感谢或询问助手能做什么
- **THEN** Agent 自然回应，不显示意图引导话术，也不触发轻量分析

### Requirement: 斜杠命令显式引用报告

对话输入框 SHALL 支持 `/ask @<报告名> <问题>` 形式的斜杠命令：`@` 后 SHALL 提供可选报告列表自动补全（官方报告与我的报告）；斜杠命令的回答 MUST 仅出自指定报告并附真实引用锚点；不带 `@` 的裸 `/ask` MUST NOT 被执行，SHALL 提示需指定报告。

#### Scenario: 显式引用官方报告提问

- **WHEN** 用户输入 `/ask @官方报告 负面反馈集中在哪些方面？`
- **THEN** 系统调用报告问答链路，回答仅引用该报告内容并带锚点，不混入报告外来源

#### Scenario: 裸 /ask 被拒

- **WHEN** 用户输入 `/ask 为什么指标下降`（未带 `@报告名`）
- **THEN** 系统不执行查询，提示用户需通过 `@` 指定报告，并展示可选报告列表

### Requirement: 回答携带真实引用锚点

轻量分析的回答（含斜杠命令路径）SHALL 附带引用锚点，锚点 MUST 真实存在于被引用报告中，并 SHALL 可供前端定位到报告中对应段落。

#### Scenario: 锚点可定位原文

- **WHEN** 对话回答中出现引用锚点，用户点击该锚点
- **THEN** 前端在报告视图中定位到该锚点对应的段落

#### Scenario: 未知锚点被拦截

- **WHEN** 生成回答中的引用锚点不存在于被引用报告
- **THEN** 系统校验失败并拒绝输出该回答，不展示虚构引用

### Requirement: 拒答与上下文预算约束

轻量分析 SHALL 继承报告问答的确定性约束：命中报告拒答清单（[R]）时 MUST 拒绝回答并说明；引用内容超过上下文预算时 MUST 显式报错并提示缩小引用范围，MUST NOT 静默截断。

#### Scenario: 命中拒答清单

- **WHEN** 用户的问题命中所引用报告的拒答清单条目
- **THEN** Agent 拒绝回答，说明该问题超出报告声明范围

#### Scenario: 引用内容超预算

- **WHEN** 被引用报告内容与问题拼接超过上下文预算
- **THEN** 系统显式报错并提示用户缩小问题范围或改用深度分析，不返回静默截断的结果
