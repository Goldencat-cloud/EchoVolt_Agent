# Spec Delta

## Purpose

让已发布深度报告的图表数据（计划 visualization 意图与 python chart）真正渲染为读者可见的图，且只画有已验证数据支撑的图。

## ADDED Requirements

### Requirement: 发布版报告渲染已验证数据图表

报告发布视图 SHALL 依据分析计划声明的可视化意图与已验证分析步骤结果，以确定性方式渲染 SVG 图表（bar/line），图表数值 MUST 与正文数字同源（均来自已验证步骤）；无对应已验证数据的工作项 MUST NOT 渲染图表。图表 SHALL 锚定到正文对应章节附近，无法锚定时 SHALL 归入文末图表附录并标注数据来源。

#### Scenario: 读者查看图表与数字一致性

- **WHEN** 读者查看已发布报告中的图表
- **THEN** 图表数值与正文及已验证步骤结果一致，图表下方标明数据来源

#### Scenario: 计划声明但未执行的可视化

- **WHEN** 某工作项声明了可视化意图但没有对应的已验证分析数据
- **THEN** 发布视图跳过该图表，不出现在报告中，也不编造占位图形
