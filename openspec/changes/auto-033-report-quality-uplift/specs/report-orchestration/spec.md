# Spec Delta

## Purpose

补齐深度 Agent 报告的可解释性最后一公里与人审结构化程度，不改变确定性门禁的能力边界。

## ADDED Requirements

### Requirement: 发布版报告附证据索引附录

报告持久化时系统 SHALL 依据报告实际引用的证据标识，从冻结精选观点池确定性生成证据附录（claim_id → 原帖链接、日期、标题、议题、情感、归属、亲历标注、所属集合与引文），使读者无需读取原始溯源文件即可复核每条引用；附录 MUST 作为独立产物存在，MUST NOT 注入 Agent 报告正文，也不在提交门禁数字溯源的校验范围内。查询不到对应观点的证据标识 SHALL 在附录中如实标注，MUST NOT 静默丢弃。

#### Scenario: 读者复核正文引用

- **WHEN** 已发布报告的读者点击或检索正文中的某个 claim_id
- **THEN** 证据附录中能找到该标识对应的原帖链接、日期与所属集合，附录内容与冻结数据一致

#### Scenario: 附录不影响门禁与人审流程

- **WHEN** 深度 Agent 提交报告并通过确定性门禁
- **THEN** 附录在持久化阶段由系统生成，报告正文与门禁校验行为保持不变，发布仍需非作者人审

### Requirement: 人工审核记录含五维结构化结论

报告审核记录 SHALL 支持附带五维结构化评审结论（可读性、逻辑性、全面性、深度、可解释性），经形状校验后与审核人、日期、审阅 commit 一并写入发布元数据；五维结论 MUST 由人工填写，系统 MUST NOT 自动生成或评分。不提供结构化结论时审核流程 MUST 保持原有行为。

#### Scenario: 审核人提交结构化评审

- **WHEN** 非作者审核人通过发布入口附带五维评审结论批准报告
- **THEN** 五维结论被完整记录在该报告的审核元数据中，可被后续追溯读取

#### Scenario: 结构化结论形状非法

- **WHEN** 审核人提交的评审结论包含五维之外的键或空值
- **THEN** 系统拒绝该输入并说明合法形状，不写入部分有效内容
