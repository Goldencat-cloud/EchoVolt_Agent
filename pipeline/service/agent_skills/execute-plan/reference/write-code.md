# 写代码：沙箱里的自定义统计

## 何时用

计划 `use_python=true`、需要图表数据、或语义聚合与白名单方法都算不出想要的形态时。

## 可用变量

- `pd`：pandas 已预载
- `frames.<name>`：语义关系导出的数据框（`frames.xx` 与 `frames['xx']` 都可用）
- `meta`：数据版本等字典

具体有哪些 frames、各自的列与行数，以 `semantic_overview` 返回的变量信息为准——会随数据版本变化，不凭记忆写列名。

## 写法规则

1. **一段代码只回答一个子问题**，并把该子问题的口径（分母是谁、哪个集合）写在注释第一行。
2. 中间量用 `print` 输出，便于事后核对。
3. 关键结论赋给 `result`（DataFrame 自动转记录列表）。
4. 一段代码保持在 40 行以内；再长说明该拆成多次调用。

## 图表

把 dict 赋给 `chart`，结构见 `python_analyze` 工具说明（`type/title/x_label/y_label/data`）。

- data 必须由 frames 计算得出，只做格式转换与排序，不重算数值
- 图表数值与已验证行数据必须同源（同源检查点见执行循环第 6 步）

## 常见错误

- ❌ 在代码里重算语义层已能算的聚合（应先用聚合查询，代码只做白名单之外的交叉）
- ❌ 把中间结果拼成一段超长代码（应拆成多次调用，每次一个子问题）
- ❌ 试图读文件或网络取"外部数据"（数据不支持就如实说明）

## 自查一句

这段代码的注释第一行，能不能写清"它在回答哪个子问题、分母是什么"？写不出就说明还没想清楚要算什么。
